# AI Sudoku Solver

## Project Description

AI Sudoku Solver is a Python-based application designed to solve Sudoku puzzles automatically using an Artificial Intelligence approach. The application provides a simple and user-friendly interface where users can solve Sudoku puzzles and view the AI solving process.

## Features

- User-friendly Sudoku interface
- Easy, Medium and Hard difficulty levels
- Automatic Sudoku puzzle generation
- AI-based Sudoku solving
- Backtracking algorithm
- Step-by-step solving process
- Timer for solving
- Success/completion screen
- Clear and interactive interface

## Technologies Used

- Python
- Tkinter
- Pillow (PIL)
- Backtracking Algorithm
- Artificial Intelligence concepts
